# i18n

## Назначение

Мультиязычный UI с сохранением выбора языка на backend.

## Правила и инварианты

- Языки: `en`, `ru` — равноправны с первого дня.
- Дефолтный язык задаётся на этапе деплоя (`VITE_DEFAULT_LOCALE` или аналог).
- Переключение языка прямо в приложении.
- Все видимые пользователю строки — через i18n; форматирование дат/чисел — по текущей локали; формат хранения — ISO / decimal-safe.
- Сохранение настроек — см. [`users-preferences.md`](./users-preferences.md).

## Нужно сделать

- Дефолт локали зашит как `en` (`readCachedLocale`, `fallbackLng`). Переменной деплоя нет.
