# Analytics и capital

## Назначение

Графики дохода/расхода и итоги в валюте отчёта.

## Правила и инварианты

- Carbon Charts; фильтры по дате / счёту / createdBy / категории / валюте.
- Никогда не суммировать операции в разных валютах без конвертации.
- Производительность: индексы, агрегаты, материализованные представления — по результатам профилирования; не Redis «на всякий случай».
