# Mobile / tablet layout

## Назначение

Решение после usable desktop MVP: нужен ли полноценный узкий (mobile/tablet) layout.

## Правила и инварианты

- Не MVP deliverable; не тратить время MVP на phone IA / bottom nav.
- Если строить — не регрессировать desktop.
