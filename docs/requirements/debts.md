# Debts и obligations

## Назначение

Долги / кредиты / рассрочки / ипотека — по мере нужды.

## Правила и инварианты

- Разные типы долгов не схлопывать в одну таблицу, если поведение отличается.
- Типичные поля: тело долга (principal), остаток, проценты, график платежей, следующий платёж, валюта, статус.
