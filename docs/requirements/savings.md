# Savings goals

## Назначение

Цели накоплений (отпуск, подушка безопасности, …).

## Правила и инварианты

- Поля: id, name, целевая сумма (Money), текущая сумма (явным числом или через связанный счёт — одна модель), опциональный дедлайн, статус, createdBy, таймстемпы, version, deletedAt.
- CRUD в едином пространстве; прогресс виден пользователю; soft-delete; decimal-safe.
- Не Budget / лимиты расходов.

## Вне целей

- Автопереводы, сложное финансирование цели, агрегация по нескольким валютам без конвертации (v1).
