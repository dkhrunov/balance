# Accounts

## Назначение

Account — место хранения денег в едином финансовом пространстве.

## Правила и инварианты

- Примеры: наличные, банковский счёт, карта, накопительный счёт, инвестиционный счёт.
- У каждого счёта своя валюта. При создании обязательны имя, валюта и `initialBalance`. После создания валюту не меняют: правка счёта — имя и прочие невалютные поля, с `version`.
- Счета **не принадлежат** пользователю; любой аутентифицированный пользователь может CRUD любой счёт (см. [`multi-user.md`](./multi-user.md)).
- Баланс считается **по каждому счёту отдельно** (в валюте счёта). Сумма `10 000 RUB + 1 000 USD` не равна `11 000` и не является одним балансом.
- Баланс **выводится (derived)** из `initialBalance` + журнал операций (ledger) (`AccountBalance.derive`) — ADR-0005.
- Soft-delete (`deletedAt`), `version` на изменяемых сущностях.
- Удаление счёта, на который уже есть транзакции, разрешено. Транзакции не удаляются и не теряют `accountId`. Имя и валюта счёта остаются доступны для истории. Удалённый счёт пропадает из активного списка и не выбирается для новой операции.

## Контракты

- `@balance/dto/accounts`

## Поведение на web

- Список/создание/редактирование на Dashboard; показывать валюту и баланс; состояния empty/loading/error. В форме создания есть валюта и начальный баланс; в форме правки валюты нет.

## Поведение на server

- CRUD + soft-delete; обязательна аутентификация; optimistic concurrency. Обновление не принимает новую валюту. Soft-delete не проверяет наличие транзакций и не каскадирует их.

## Нужно сделать

- Имя и валюта soft-deleted счёта не читаются: выборки счетов отсекают `deleted_at`, в транзакции только `accountId`.
